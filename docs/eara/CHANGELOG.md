# Enterprise AI Readiness Assessment changelog

## 1.1.0-beta — 2026-08-01

### Changed
- Repositioned the hero around the CIO decision: where to begin before further enterprise AI investment.
- Added explicit competitive framing: this is a decision diagnostic, not a software selector or compliance certification.
- Moved privacy proof above the first click: no login, and responses remain in the browser.
- Added a methodology and limitations section explaining multi-leader use, evidence validation, and the directional nature of the score.
- Added a restrained evidence accent color to distinguish methodology content from assessment status.
- Repeated the primary action after methodology to support users who need proof before beginning.

### Fixed
- Corrected uniform-score logic so the same dimension is not presented as both the primary constraint and strongest foundation.
- Added explicit guidance that tied scores create a starting hypothesis, not a proven priority.

## 1.0.0-beta — 2026-08-01

### Added
- Six-dimension Enterprise AI Readiness Assessment.
- 36-question guided assessment covering strategy, data, processes, governance, people, and technology.
- Local-only response handling, readiness scoring, executive decision guidance, and a prioritized 90-day roadmap.
- Printable executive brief and responsive desktop/mobile layouts.
